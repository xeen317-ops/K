이름 찾아 연결 —

장면·컷·인물·복선에 글자로만 적힌 이름을 찾아 인물 표의 인물과 연결합니다. 연결된 이름은 @이름으로 보이고, 인물 표에서 이름을 바꾸면 모든 곳이 함께 바뀝니다. 다른 뜻으로 쓰인 곳(예: ‘하나씩’의 하나)은 체크를 빼세요. 흔한 낱말과 같은 이름(하나, 나라 등)은 시점 인물·등장 인물 칸에 적힌 것만 체크되어 있으니, 인물이 맞는 곳은 직접 체크하세요.

깃허브 동기화

이 트리트먼트를 깃허브 저장소의 JSON 파일 하나와 주고받습니다. 같은 설정을 넣은 다른 기기(사무실 PC, 집, 폰)에서 열면 그 파일을 받아 이어 씁니다. 동기화 한 번 = 깃허브에서 받기 → 합치기 → 올리기. 두 기기에서 따로 고쳤으면 칸 하나하나를 더 나중에 고친 쪽으로 남기고(같은 장면의 다른 칸은 둘 다 남습니다), 지운 항목은 지운 것으로 전해집니다.

고급 (보통은 그대로 두세요)
토큰 만드는 법 · 주의 업무일지에 넣어 둔 토큰을 그대로 써도 됩니다(같은 저장소라면). 새로 만들 때는 GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Repository access는 데이터 저장소 하나만, Permissions는 Contents: Read and write만 주면 됩니다.
토큰은 이 브라우저에만 저장되며 JSON 내보내기나 깃허브 파일에는 들어가지 않습니다. 남과 같이 쓰는 컴퓨터에서는 쓰고 나서 ‘설정 지우기’를 누르세요.
첫 동기화 때 그 파일이 없으면 지금 내용으로 새로 만듭니다. 깃허브의 커밋 기록이 그대로 변경 이력이라, 되돌리려면 History에서 옛 버전의 JSON을 받아 ‘JSON 가져오기’로 넣으면 됩니다.

칸에서 오른쪽 버튼 → AI 모티브 합성을 누르면, AI가 그 칸의 맥락(작품 · 권 · 장 · 인물 표)을 읽고 고전 원형 하나와 기존 장르소설 · 애니메이션 · 게임 n개 이상에서 모티브만 골라 이 세계의 문장으로 제안합니다. 무엇을 참고해 어떻게 비틀었는지 먼저 보여 주고, 넣기를 눌러야 칸에 들어갑니다.

지시문 구조 보기 — AI에게 무엇을 시키는가 합성할 때마다 아래 지시문에 그 칸의 맥락(작품 · 위쪽 권과 장 · 앞뒤 흐름 · 인물 표 · 안 거둔 복선 · 그 항목의 다른 칸)이 붙어서 나갑니다. 칸의 종류(인물 표 / 작품 · 권 / 장 · 소단락 / 장면 · 컷 / 복선)에 따라 ‘이 칸의 성격’이 바뀝니다. 아래는 장면 · 컷일 때입니다.
키 · 비용 · 주의 키는 이 브라우저에만 저장됩니다. JSON 내보내기나 깃허브 파일에는 들어가지 않으니, 다른 기기에서는 다시 넣어야 합니다. 남과 같이 쓰는 컴퓨터에서는 쓰고 나서 ‘설정 지우기’를 누르세요.
API 키는 Claude 앱이나 argon 앱의 구독과 별개입니다. 각 회사의 개발자 화면에서 따로 발급받고, 쓴 만큼 요금이 나갑니다. 사용 한도를 걸어 두기를 권합니다.
fable5.2는 생각한 양만큼도 요금이 나갑니다. 노력이 높을수록 오래 생각하니, 한 번에 드는 값과 시간이 크게 늘 수 있습니다. 한 번의 상한은 엑스트라가 출력 6만 4천 토큰, 최대값이 12만 8천 토큰입니다.
합성은 이 브라우저에서 각 회사의 서버로 바로 요청합니다. 칸의 맥락(시놉시스와 인물 표의 일부)이 그 요청에 실려 나갑니다. ‘주소’를 바꾸면 키와 맥락이 그 주소로 갑니다.
키가 없어도 이 칸의 AI 지시문 복사로 같은 지시문을 대화창에 붙여 쓸 수 있습니다.
